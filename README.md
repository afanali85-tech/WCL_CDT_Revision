
# Cognitive Digital Twins for Self-Aware Channel Estimation

This repository contains the Python implementation
and simulation notebook accompanying the manuscript:

**Cognitive Digital Twins for Self-Aware Channel Estimation**

Submitted to IEEE Wireless Communications Letters.
Manuscript ID: WCL2026-2358.

## Overview

The framework includes:

- Baseline FCN channel estimator
- VAE-based pilot distribution monitoring
- Activation statistics drift detection
- Autonomous CONTINUE, UPDATE, and RETIRE decisions
- VQ-VAE-based generative estimator replacement
- Adapted CLCE, AttRNet, and SCCENet benchmarks

## Implementation

Python, PyTorch, and CUDA.
